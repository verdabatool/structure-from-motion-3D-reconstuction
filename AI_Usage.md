# AI Usage Declaration

## Overview
We use AI assistance throughout this **3D Scene Reconstruction and Virtual Tour** project, from initial concept understanding to final report writing. AI served as both an educational resource and a development assistant across all project phases.

## Week-by-Week AI Usage

### Week 1: Setup & Feature Matching
**Conceptual Understanding:** Used AI to explain SIFT features, Lowe's ratio test, and feature matching algorithms.  
**Code Structure:** Generated boilerplate for image loading, SIFT detection, and feature matching functions.  

### Week 2: Two-View Reconstruction
**Mathematics Explanation:** AI explained essential matrix, triangulation, and cheirality checking in simple terms.  
**Algorithm Implementation:** Generated initial implementations for `estimate_essential()`, `decompose_essential_to_poses()`, and `triangulate_points()`.  
**Visualization Code:** Created 3D plotting code with matplotlib for point cloud visualization.  
**Error Resolution:** AI helped debug pose disambiguation logic and PLY file format issues.

### Week 3: Multi-View SfM & Refinement
**Complex Algorithm Explanation:** AI explained PnP (Perspective-n-Point), bundle adjustment, and drift accumulation.  
**Code Extension:** Generated incremental SfM pipeline structure and bundle adjustment implementation.  

### Week 4: Interactive Visualization
**Three.js Learning:** AI explained Three.js concepts, camera interpolation, and PLY loading.  
**Viewer Implementation:** Generated initial Three.js setup code and camera transition logic.  
**Web Development:** Created HTML/CSS/JavaScript boilerplate for the virtual tour interface.  

### Week 5: Final Report & Documentation
**Report Writing:** Helped structure the methodology section and explain technical concepts in accessible language.  
**LaTeX Formatting:** Generated LaTeX templates and fixed formatting issues.  
**Results Analysis:** Assisted in interpreting quantitative results (8.2% bundle adjustment improvement) and explaining limitations.

## Ethical Considerations
- Focused on understanding before implementation.  
- Adapted and modified AI-generated code for project-specific needs.  
- Maintained transparency through this declaration.  
- Used AI as an educational aid, not a substitute for learning.
